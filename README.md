## `03` — Mathematics Behind the Models

<div align="center">

**Linear Regression**

$$
\hat{y} = X\beta + \epsilon
$$

**Mean Squared Error**

$$
MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2
$$

**Gradient Descent**

$$
\theta_{t+1}=\theta_t-\alpha\nabla J(\theta_t)
$$

</div>

> Mathematics provides the foundation. Data provides the evidence. Machine learning connects the two.
